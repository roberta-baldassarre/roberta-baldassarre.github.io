# Travel guide template

Copy travel-guide.html into la-trottola/your-destination.html. Replace DESTINATION, SUBTITLE, and INTRO tokens, then edit all three itinerary stops, tags, and editorial notes. Paths are relative to la-trottola/. Keep the draft label until personal recommendations and practical details have been approved. Add a destination card in explore.html and index.html. Shared site.css, site.js, header, itinerary sections, sidebar, and print styles provide the reusable layout. Do not publish the template itself as a finished guide.
